# Drawable Shapes System

## About the Project

Drawable Shapes System is a Java application developed to demonstrate object-oriented programming concepts through the representation of geometric shapes and the calculation of their properties.

## Features

* Represents geometric shapes using Java classes.
* Demonstrates inheritance and polymorphism.
* Uses abstraction and interfaces.
* Supports calculations related to geometric properties.
* Organizes shape-related functionality using object-oriented design.

## Technologies Used

* **Programming Language:** Java
* **Concepts:** Object-Oriented Programming (OOP)

## Project Structure

| File               | Description                                   |
| ------------------ | --------------------------------------------- |
| `Circle.java`      | Circle-related class                          |
| `Cube.java`        | Cube-related class                            |
| `Shape.java`       | Shape abstraction or base class               |
| `ThreeDShape.java` | Three-dimensional shape class                 |
| `Drawable.java`    | Drawable interface or component               |
| `DrawPanel.java`   | Drawing-related panel                         |
| `Project.java`     | Project entry point or main application class |

## Learning Objectives

This project provides practical experience with Java classes, inheritance, polymorphism, abstraction, interfaces, and object-oriented program design.
